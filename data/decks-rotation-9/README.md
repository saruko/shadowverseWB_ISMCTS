# 第9弾環境のローテーションのデッキ

このディレクトリの `*.txt` は、第9弾環境（ベーシック＋第4〜9弾。`src/cards/format.ts` の `ROTATION_9`）のローテーションのデッキです（形式は `data/decks/README.md` と同じ）。
2026-10-25 に作り、第10弾の追加（2026-10-27 に公式のデータで第4弾がローテーションから外れた）の後も、このフォーマットのデッキとして残しています（ユーザー判断 2026-10-27）。
ローテーションの補正（`data/value-net-rotation.json`、m1）は、この 14 デッキの自己対戦で学んだものです。
`npm run sim -- --format rotation9` で AI 同士を総当たりで対戦させられます。Rust のコマンド（`svwb compare --decks`・`td selfplay --decks`・`meta init --decks`）には、ファイルのパスを渡します。

- `npm test` で、すべてのファイルが第9弾環境の構築ルール（40枚・同名3枚まで・クラス・第9弾環境のローテーションで使えるカード）を満たすか検査します
- 各ファイルの先頭のコメントに、出典と選び方を書いています

## 選び方（2026-10-25）

アーキタイプは GameWith の「第9弾ローテ最強デッキTier表」（2026-10-25 更新）の 14 個です。

- Shadowverse Premier Series 26-27 の公式デッキリスト（[第8節 後半](https://ps.shadowverse-wb.com/26-27/news/352/)・[第9節 後半](https://ps.shadowverse-wb.com/26-27/news/365/)、計 56 リスト）にあるアーキタイプ（10 個）は、同じアーキタイプのリストのうち、ほかのリストとの違い（入れ替わる枚数の合計）が最も少ないものにしました。同じなら新しい節のもの
- 公式デッキリストに無いアーキタイプ（AFネメシス・進化ネメシス・連携ロイヤル・監獄ビショップ）は、[GameWith](https://gamewith.jp/shadowverse-wb/497197) のデッキレシピのリストです

公式デッキリストのアーキタイプは、クラスと次のカードで分けました: ウィッチは万術の咎人・セフィーがあればセフィーウィッチ、無ければスペルウィッチ。ナイトメアは激烈の副総長があればアグロナイトメア、無ければミッドレンジナイトメア。ビショップは霧巻花・クキシロがあればクキシロビショップ、無ければアミュレットビショップ。ほかのクラスは 1 つずつです（コンボエルフ・海賊ロイヤル・ランプドラゴン・ハイランダーネメシス）。

名前がスターターのデッキ（`data/decks`）と同じものがありますが、中身は別です。

## デッキコードの読み方

公式のデッキのリンク（`https://shadowverse-wb.com/ja/deck/detail/?hash=1.<クラス>.<カード>.<カード>…`）は、
クラスが 1〜7（エルフ・ロイヤル・ウィッチ・ドラゴン・ナイトメア・ビショップ・ネメシス）、
カードが 1 枚ずつ 4 文字の 64 進数（`0-9A-Za-z-_` の順）で、値がそのままカードID（`data/cards.json` の `id`）です。
公式デッキリストのページの中身は `https://ps.shadowverse-wb.com/rcms-api/1/news/detail/<記事番号>` の JSON（`deck_list`）にあります。
GameWith のデッキレシピのページにも同じ形のリンクがあります。
