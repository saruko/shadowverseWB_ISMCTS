# ローテーションのデッキ

このディレクトリの `*.txt` は、今のローテーション（ベーシック＋直近6パック。第10弾の追加後は第5〜10弾）のデッキです（形式は `data/decks/README.md` と同じ）。
`npm run sim -- --format rotation` で AI 同士を総当たりで対戦させられます。Rust のコマンド（`svwb compare --decks`・`td selfplay --decks`・`meta init --decks`）には、ファイルのパスを渡します。

- `npm test` で、すべてのファイルがローテーションの構築ルール（40枚・同名3枚まで・クラス・ローテーションで使えるカード）を満たすか検査します
- 各ファイルの先頭のコメントに、出典と選び方を書きます

## 第10弾環境のデッキ（2026-10-27）

ユーザーが提供した 14 枚のデッキ画像（公式のデッキ画像）から作りました。カード名は画像から読み取り、`data/cards.json` の名前に照合しました
（画像では長い名前が途中で切れているので、クラス・コストと文字の近さで照合。照合の結果は 14 デッキとも目で確かめた）。
デッキの名前は中心のカードから付けた仮の名前です。画像の順は各ファイルの先頭のコメントにあります。

公式デッキリスト・GameWith の Tier 表が出たら、出典と見比べます。
それまでのデッキ（第9弾環境の 14 個）は `data/decks-rotation-9/` にあります（選び方とデッキコードの読み方もそちら）。
